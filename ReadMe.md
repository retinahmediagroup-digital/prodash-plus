# ProDash+
CRM and B.I-led sales-push platform for Prodairy, built and operated by RMG Digital.

-'sql/' - database schemas and migrations
- 'ingestion/' - CSV loader (bronze)
- 'dbt' - silverand gold models
- 'scoring' - RFM, lapse and priority scoring
- 'web/' - Next.js web application
- 'docs/' - architecture, data dictionary, runbooks

Customer data never goes in this repository.
